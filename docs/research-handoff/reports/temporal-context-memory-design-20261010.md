## 记忆与四条件最小消融

同一target、固定候选及ROI：A当前图；B加短期记忆；C加跨日近时段背景；D同时加两者。原始短时帧可见条件另记B_raw，不能与记忆摘要混称同一机制。C2背景候选先冻结前一日同钟点±5分钟窗口，缺失则missing；当前素材未凑齐同target四条件，暂不运行效果实验。

记忆绑定camera/scene/rule版本、区域、原帧哈希与源时间；分离人工明确确认、AI猜测和不确定意见。仅记录任务所需可见要素，不做身份画像。类似反光背心/颜色可以引导复查，不能认证同一人。

TTL=10分钟、半衰期5分钟仅为拟冻结开发参数，未经优化验证。S120到S121为4分19秒，S06到S121为46分03秒；后者按该候选规则过期。显示相邻不代表时序相邻。无新证据不刷新TTL；机位/区域版本变化失效；当前猜测不能经旧记忆循环自证。

保留无目标历史、错误历史、过期记忆三种反证条件。错误历史明确标注受控扰动，原图不伪造；无目标历史需要独立完整负标注。已有D06-S05非真人照片判断可用于同camera污染防护，不能跨camera注入C作为有效历史。

## 评估边界

记忆只引导复查，不替当前像素、对象归属、精确框或GT。无GT只描述解释变化、unknown和冲突，不算准确率。背景与记忆证据应随camera/time-block划分，同一源帧、背景、事件和记忆库不跨训练/测试共享；禁止随机帧切分造成泄漏。全部已有镜头仍是dev_seen。

## 固定视野记忆的两层定义

记忆主键应为fixed_view_scene_id + view_version，camera ID只是来源线索。同一物理相机转动、变焦或重定位后必须版本化与失效，不能继承旧像素区域，也不跨不同视野共享相似外观历史。

长期层记录窗、照片、反射易发区与结构锚点，并保留来源/最近核验；短期层记录近期出现要素，额外受TTL/衰减约束。长期不是永久GT，布局或外部施工变化需重核；短期相似衣色仅召回待核线索。当前真人遮住历史照片位置时不能被静态区域黑名单排除。

未来机制消融可拆static_only、recent_only、static_plus_recent，并与raw_cross_day_background区分；当前先保留未执行的最小四条件，素材齐后再预注册增项，不悄然改冻结16图。
