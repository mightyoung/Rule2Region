# Fixed-view memory: no-model slice and independent review

A standalone synthetic reference reducer was tested without model calls or original data changes. Its initial 20 unit tests passed, but independent review found two missing counterexamples: unverified events could fill date/time-band promotion gates, and unaligned short-term evidence could remain usable. Both were reproduced as failures before fixing. Revision 02 passes 22 tests and exactly replays 29 saved hypothetical outputs. These are bounded regression results, not acceptance of the research pipeline or evidence of model benefit.

The corrections use the same verified-event subset for pattern event/date/time-band coverage and exclude unaligned evidence before support aggregation. Original code/results are preserved. Parameters remain development-smoke values, not optimized thresholds.

Independent review also identified required admission work: validate original visual ancestry so summaries cannot invent source groups; bind every human review to the card's exact object/region/predicate; and separately qualify long-term review refresh. The current reference does not estimate event frequency or implement frequency-driven degradation. It has no production dependency graph, source-retention service, retrieval-budget scheduler or end-to-end LLM safeguards. Automatic filtering is disabled.

Material audit found no missing/hash-mismatched local inputs among 77 paths and 101 expected-hash references (repeated references are not independent samples). The 21-frame same-day sequence spans 23 seconds; its first frame is identical to the earlier reviewed target. If that first frame is the target, all later sequence frames are future evidence, not history. The cross-day pair in another view is not a substitute for a missing same-target condition. Historical label availability remains unestablished; receipt times do not establish historical online availability.

All existing views remain development-exposed. Existing partial class/scope decisions remain partial; no new ground truth, real card promotion, precision/recall or visual-memory improvement is asserted. The next step is to close admission contracts and obtain a complete same-target context/adjudication group before a separately frozen effect run.

A retrospective reviewed-label replay must be explicitly designated simulated/oracle history, not authentic online replay.

## Remaining entry gates

- Require a visual source kind and original-ancestor mapping before counting evidence. The reference only deduplicates correctly normalized source groups; repeated model summaries are not new visual observations.
- Bind reviewed fields to each card's exact subject, region version and atomic predicate. A scope decision or shirt-colour review must not satisfy a photo-class confirmation gate merely through a provenance string.
- Establish qualified observation opportunities/duration before frequency quantifiers or rate estimates. Observation denominators and frequency-driven degradation remain unimplemented. Separate qualified long-review refresh from any new raw support; an unverified event must not silently revalidate an expired real card.
- Before an explanation layer, expose qualified-event date/band counts and gate-source IDs. Current general support-date counts cannot alone explain promotion decisions.

Development-smoke parameters remain TTL 600 seconds, ranking half-life 300 seconds, structure gate 3 sessions/2 dates/1 explicit class review, pattern gate 5 events/3 dates/2 time bands, and a 7-day review interval. These are test parameters, not optimized values or empirical findings.

The original 20-test revision is retained, including its limitations. Independent rechecking confirmed revision 02's 22 saved tests, 29 replay outputs and recorded script/parameter hashes. Additional reviewer spot checks are not added to the saved-suite count. Complete-GT metrics remain null. This report appends documentation only; the original 16-image predictions, prior partial-review documents and model-experiment scope are unchanged.
