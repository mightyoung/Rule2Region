# 下次获授权执行时的日志要求（本轮不执行模型）

此前两次模型运行有结果JSON、原张量及会话退出记录，但落盘日志缺独立启动/命令/PID/退出标记；pip check也缺单独原stdout/exit文件。保留此缺口，不从mtime、结果JSON或转述拼造历史启动回执，不为补日志重跑本轮两次推理。

下次启动前在新的、不可覆盖旧运行目录中保存：

1. 私有原始argv数组、cwd、runner脚本SHA、UTC启动时间和单调时钟；只记录必要离线参数，不导出环境凭据。公开版剥私有路径，与原记录分开。
2. 实际输入原图大小/SHA、模型9文件逐项核验结果、配置/依赖锁版本及SHA；处理输入导出后记录实际张量文件SHA和shape，不能只复述预期值。
3. 子进程启动后PID；原stdout/stderr单独落盘。pip check独立运行并保留原stdout/stderr/exit，不能用后续命令的exit替代。
4. 退出时UTC/单调结束时间、actual exit code、失败/信号状态及已产生输出清单；出错也保留记录。模型原张量、处理输入、结果回执逐项大小/SHA，缺文件明确missing，不能补成成功。
5. 是否真正调用model.forward、调用次数/输入种类及计时边界。命令启动并不等于推理完成，重放张量也不等于forward；输入输出hash相同不单独证明发生新调用。

以上是下次执行的操作要求，不是本轮新执行回执、已实现的自动记录器或新增标注协议。本轮模型调用0、安装/下载0、媒体传输0，逐图unknown/未审状态保留。
