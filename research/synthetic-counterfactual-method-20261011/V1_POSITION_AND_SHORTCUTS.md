# v1 开发定位与潜在捷径（保留原版，不重标）

v1 是6个分别编写的简单三区域/两门几何计划、12个物理门、24张静态双侧RGB的渲染与数据分离开发样例。不是检测增益实验、物理外连基准、整栋楼人数验证，也不是人工图像真值。全组 development_staging，split=null；全部单图外连标签仍null。父线程尚未通过正式文件通道看到实际图。Library正式流程认证HTTP401后停止，不重试、不给同一素材换路。

隐藏字段 direct_exterior_connection 的原义是门是否连接该计划指定的开放院地。这只是真值生成时的源几何定义：不得重新解释为一般 indoor/outdoor、真实建筑围护边界或用户选择的存量人数计数边界。源院地可有物理开放特征，但是否属于所选计数范围要由另外的边界政策决定。S物理围护与B计数范围目前仅是待核的研究操作化方案，未获用户业务定义确认；默认单栋建筑目标不自动包含院地/连廊。原版标签、图像、源码、失败记录、manifest与ZIP均保持字节不变。

| 因素 | v1中实际情况 | 对下一版的约束 |
|---|---|---|
| 屋顶/天空/围墙 | 外部院地固定无屋顶、低围墙，可能看见同一种蓝色世界背景 | 是场景中真实可见的物理线索，但与当前院地标签捆绑；必须加入有顶外部连廊、开敞内部中庭及不同天空/同天空不同拓扑，不能把线索当充分条件 |
| 材质/色调 | 外连标志不参与配色；每布局共用一套中性色，色调随布局种子改变 | 无显式标签涂色，但小样本中布局与色调仍可偶然相关；同关系换外观、不同关系用同外观，整个布局族隔离 |
| 光照 | 固定世界背景、太阳及区域灯；封闭/开放几何改变照明 | 光照差可能成为捷径；换光照应保留关系，改变关系应有匹配光照对照 |
| 拓扑/构图 | 全部三节点路径；最近中央门、固定镜头/距离、双侧，统一完全打开的门叶 | 距离、居中构图、门叶遮挡不能成为关系标签；共同拓扑/模板不能支撑泛化结论 |
| 生成器噪声/伪影 | 16样本、无去噪、共同Blender风格；首轮黑共享墙已整批修正 | 噪声、修正批次、文件日期等不得进入模型输入；保留失败而非混入训练 |
| 命名/元数据 | 输入是20位不透明ID；Scene/Camera等原生PNG元数据已移除 | ID只作连接键；不能作为特征。原生PNG只在审计树中，不给算法 |
| 真值/分组 | 输入树与源码、几何真值、分组树分目录；审计ZIP同时包含所有树 | 这是逻辑目录隔离，不是访问控制。算法只交付输入子树；分组仅用于隔离，不作特征 |
| 可观测性 | 物理图已知，不代表单幅能辨建筑范围或计数范围 | 未知不能从隐藏图强填为可见标签；图像审阅与物理/政策真值分字段 |

必要线索因目标而异。局部RGB能支持门口/开口等可见几何，未必支持完整封闭体、建筑隶属或管理范围。可靠全局拓扑/边界政策是计数关系的必要输入之一；在有权提供时可以明示，缺失则unknown。不是任何可见天空都泄漏，也不是任何屋顶都证明室内；要以反事实配对检验该线索是否充分、必要或仅偶然相关。

轨迹/方向继续记录：本版无人物、时间序列或穿越，trajectory=null，direction=null、证据不可用。未来方向只能描述相对于指定门法向的运动；必须结合端点所属计数范围才可认定进/出，不靠方向变化推断外连或安全。
