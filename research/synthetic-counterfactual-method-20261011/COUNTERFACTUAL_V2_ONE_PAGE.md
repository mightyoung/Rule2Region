# 下一版反事实验证草案（一页；未渲染、未训练）

**目标。** 验证“规则→可审阅边界/ROI配置”是否能在所需输入可用时区分物理关系、计数关系与不可观测；不以v1样例证明识别增益。

**先提出、再确认两个语义。** 物理侧拟用明确的建筑围护体积 S 定义内/外（开门不删除其室内体积；此约定待审阅），并另记 enclosed / sheltered_open / open_air；中庭可在建筑平面范围内、却在封闭体外，有顶连廊也可在封闭体外。管理侧由用户选定、版本化的区域集合 B 定义存量计数范围；B可包括院地/连廊，不等于S。S/B都是待核的研究操作化方案，尚未获得用户业务定义确认；默认单栋建筑目标不自动包括院地或连廊，不推定B包含这些区域。门端点u,v的 `count_boundary_crossing = [u∈B] XOR [v∈B]`；内部门不更新存量。同一门运动从B外到B内才是入，反向才是出。N_B=N_0+入−出还需要可靠初值、覆盖和去重，不能由静态门图直接验证。

**最小4个配对族。** 每族一个目标门、两条件、每条件两观察侧，共16个“视图×条件”记录；政策对复用2张原图，最多14张不同RGB，不计作16个独立样本。

| 族 | 两条件及固定项 | 可检验预期 |
|---|---|---|
| A 屋顶反例 | 室内走廊 / 有顶外部连廊；同门结构、相似可见顶面与材质 | 屋顶存在不是围护内的充分条件；全局不可见时物理判断unknown |
| B 天空反例 | 开敞内部中庭 / 建筑外院地；相同门结构、天空与材质，改变全局拓扑/建筑范围；B分别明定 | 相同背景不能决定计数关系；中庭开放特征与计数归属分开 |
| C 外观不变性 | 同门、同拓扑、同S/B；仅换背景/天空、材质与光照 | 关系应不变；允许图像证据充分性随可见性改变，不要求置信度相同 |
| D 政策反事实 | 同几何、同门、逐像素相同RGB；B包括/不包括门另一侧区域 | 物理关系不变、计数关系变；仅RGB不能区分。给合法政策上下文后由规则计算，不算视觉识别增益 |

**隔离。** 同源布局、拓扑编辑、门、双侧、材质/光照、政策及复用图全部并入一个来源族；跨族共享布局或相同标准化解码RGB哈希时再合并连通分量。先隔离完整分量，再考虑拆分；借用v1布局须并入原v1组。四族仅开发、split=null；真正评估需另行审阅的新来源分量，不能拆配对或视角做holdout。

**输入分层与可用性。** I0仅RGB和通用任务说明：门目标可由可审阅ROI指定，不携带S/B标签。I1可加正式可用的边界政策版本、所选区域集合及经核验的相机/门到地图对应；只给在真实运行也能获得的内容，不借模拟器隐藏图、sceneID或roomtype补齐。不确定关联须显式unknown。若I1把端点范围明确给出，XOR是配置执行测试，不是视觉模型发现拓扑。轨迹版还须有真实可用的帧序/时间、轨迹与方向证据、遮挡/漏检状态；静态版均记不可用。

**标签与验收。** 分离 source_physical_truth、source_policy_truth、image_evidence（known/insufficient/unreviewed）、input_available 和 decision（含unknown）。源图只写前两者；人工审阅只能凭分配给该输入层的材料判证据，父线程尚未看图，当前不指定可见标签。先查16记录覆盖、配对固定项、输入清单和分组，再审A/B能否推翻屋顶/天空充分条件、C关系不变、D同RGB的I0不可判别与I1政策响应。保留失败/abstention，不以隐藏真值强迫输出或把unknown当安全；禁止用这四族拟阈值又报泛化成绩。
