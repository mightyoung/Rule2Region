## 已发生的v1生成事实

- 用执行环境已有的 Blender 4.3.2 / Cycles CPU 实际生成6布局、12物理门、24双侧640×480 RGB；4线程、每像素16样本、关闭去噪。未安装、下载模型或素材、运行视觉编码器、训练关系头。
- 六个计划尺寸/门位不同，但共用三区域两门路径与美术风格，只是开发样例。12个门中3个连计划指定的开放院地，9个连其他封闭区域；此源几何字段不是用户计数边界，也不是人工图像标签。全部单图外连标签仍null、待审；所有split=null。
- 图像解码、24个唯一输入SHA、6×2×2覆盖、24个门侧矩形包含探测和来源分组检查通过。24个输入PNG无元数据，解码RGB与各自保留的原生PNG完全一致。检查是包和几何合同验证，不是识别精度。
- 初始烟测因缺少OpenImageDenoise失败；关闭去噪后成功。首轮共享墙重叠造成黑区，保留10张已完成图后中断，合并共享墙并整批重渲染24张。后续输入检查拒绝原生PNG元数据，保留原件并生成像素不变的无元数据副本。原文件与失败记录均保留；低采样噪点仍是限制。
- v1没有人物、帧序轨迹或穿越事件；trajectory=null、direction=null，不能把双侧视图当时序或运动方向。方向变化只是事件证据之一，unknown不等于安全。
