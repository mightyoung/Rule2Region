# Building Boundary Pilot v1 — frozen 2026-10-11

业务规则 → 候选边界、镜头责任、ROI 和方向 → 校验 → 人确认 → 固定执行器。
独立候选应用；不替换冻结 16 图主协议，不使用 task/research-handoff-v1。
本版本是有限样例的软件验证，不能声称自动配置模型效果。先证明配置错误可观测且配置有价值，再考虑训练。

## 目标与计数定义

* 整栋占用 B(t)：楼内所有区域的人数，已知 B(0) 加外部→楼内流入减楼内→外部流出。内部换房、楼梯、电梯不改变整栋人数。
* 楼层占用 Fk(t)：明确归属该层的区域人数，已知 Fk(0) 加所有跨该层边界的流入减流出，包括外门、楼梯、电梯；同层换房不变。小试把垂直通行抽象为离散原子转移，不含在途区域；真实试验必须明确楼梯/电梯在途人数归属或独立 transit 区域，不能把此抽象当现实证明。
* 外门净流量 Dd([0,t])：某物理外门的进入次数减离开次数，无占用初值；进后重出必须分别记录。多个外门净流量求和等于 B(t)-B(0)，不等于 B(t)。人次与去重人数不是同一个指标。

## 输入/输出合同（JSON，版本 building-boundary-v1）

输入：goal（building/floor/external_net）、区域集合与楼层归属、完整物理通道清单及端点 a/b、物理门 ID 与同门镜头清单、标准化画面坐标、每镜头候选线段/ROI、规则说明、独立初始人数。小试 planner 只读 topology.json 与 goals.json，禁止读 states_gt/events_gt/observations。不可从 door 类别推定外门、整栋边界或方向。

候选配置：strategy、schema_version、目标 ID→每通道 owner_camera、a/b 对应线段两侧、roi 矩形、crossing_line；proposal 与 synthetic_fixture_approval 分开记录。每目标每物理通道只允许一个责任镜头；其他镜头备查不累加，不依赖跨镜身份关联。真正使用模型时记录模型/提示版本、输入 manifest、候选 SHA、人工修改数与审核时间。未调用接口保持 NOT_RUN，分数为 null。

固定执行器输入：镜头局部 track_id、时间步、prev/next 归一化位置；没有全局 GT 身份或 GT 事件 ID。仅负责线段穿越且位于 ROI 的观测计数，零点触线不计。owner 镜头承担全部该门流量，假设其同步可见且完整；遮挡/失步不是当前研究变量。配置 SHA 绑定夹具审批收据。生产审批、检测器/跟踪器调用均未启动。

输出：准入状态与 reasons，配置 SHA，逐时间/逐目标流入流出和预测，误差 MAE、最大绝对误差、末值误差；事件 TP/FP/FN 按(step, physical door, a→b/b→a)多重集合匹配。GT 是独立手工人物位置状态账本与手工过门事件账本，绝不能由计数器预测产生。非法配置不产生正式分数；可显示明确标注的强制诊断 replay，用于揭示错误而非策略成绩。

## 可检验准入

1. 初始值存在、非负整数、逐层之和等于整栋；缺失返回 UNKNOWN。
2. 区域、通道端点、镜头 ID 有效。每个目标边界由完整拓扑两端 membership 异或确定。不能遗漏外门、消防/服务通道、楼梯、电梯或把内部通道当外门。
3. 边界通道恰好覆盖一次，同门多镜头唯一 owner，owner 有合法 ROI、非退化线段与明确方向；通道责任不能冲突，标准化几何在 [0,1] 内。
4. 固定观测与执行器在所有策略相同；禁止用 GT 搜索 ROI、调阈值。此夹具几何由作者定义，没有视觉推断。
5. 覆盖无法证明、初值未知、方向无法确认、责任歧义、几何缺失时拒绝自动部署并保留 UNKNOWN/REJECTED，不补零。

## 冻结样例与对照

一栋两层、3 个外门（含服务门）、2 个同层内门、楼梯、电梯，同门两镜头；初始 3 人（1 层 2，2 层 1），入后出、内部换房、上下层、两个外门同时进出。有限 12 个转移，所有镜头无噪声；这是拓扑/事件软件实验，不是视觉模型实验，也不是训练/正式 test。

接口槽：manual_truth（作者真值配置）、door_only（只门候选负对照）、metadata_rule（实际运行的透明确定性拓扑编译器）、model_candidate、model_plus_metadata_or_plan（两者均 NOT_RUN）。metadata_rule 是额外机制基线，不能填进模型槽冒充模型。manual_truth 是合成作者配置，不是用户批准的真实部署配置。

预先规定通过：独立状态与事件账本一致；manual_truth/metadata_rule 全程所有目标误差 0；缺失服务门、遗漏垂直通道、双责任、反方向、未知初值、缺失 ROI 等失败可检出。仅 door 对照允许展示诊断误差，但必须拒绝正式准入。自动配置价值只到“有完整元数据时规则编译器能输出正确配置，错误配置会产生计数偏差”；不证明 LLM 能识图/节省人工审核时间/泛化。
